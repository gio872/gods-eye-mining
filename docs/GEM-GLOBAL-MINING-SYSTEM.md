# GEM — Global Mining Intelligence Operating System

GEM is designed as a planetary decision system for exploration companies, governments and private capital. It connects evidence to an auditable exploration decision.

Core loop: PLANET -> DISCOVER -> TARGET -> DECIDE -> INVEST -> DRILL -> LEARN

Capabilities to absorb from leading mining practice:
- Mineral systems: model geological processes, not only known deposits.
- National geoscience: fuse geology, geochemistry, geophysics and hyperspectral evidence.
- Satellite mineralogy: use spectral fingerprints and alteration mapping.
- 3D geology: maintain living, updateable geological and drill hypotheses.
- Mine planning: preserve repeatability, validation and data lineage.
- Strategic minerals: combine prospectivity with supply and commodity context.
- Mine waste: treat tailings and waste as potential secondary resources.
- Governance: make material decisions reproducible, auditable and secure.

GEM does not copy proprietary vendor code, models or databases. It implements interoperability contracts and uses licensed, public or authorised enterprise data.

Every production target should carry: target ID, run ID, model version, feature version, provenance, evidence channels, contradictions, evidence gaps, confidence, coverage, next-best action and validated economics only when authoritative data exists.

Audience modes:
- Mining companies: exploration portfolio, target ranking, drill planning and technical diligence.
- Governments: national mineral potential and strategic mineral security.
- Private funds: discovery pipeline, diligence readiness, supply context and risk.

Strategic universe: gold, silver, PGEs, copper, lithium, nickel, cobalt, graphite, manganese, rare earth elements, tungsten, tin, niobium, tantalum, vanadium, uranium, chromium, zinc and lead.

Trust rule: a GEM prospectivity score is not a mineral resource, reserve, grade, discovery probability or economic valuation.

Scaling doctrine: PUBLIC PLANETARY DATA -> PRIVATE EVIDENCE -> PROPRIETARY MODELS -> DECISION -> FIELD/DRILL FEEDBACK -> LEARNING.
